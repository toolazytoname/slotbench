# slotbench — 项目说明

> 推荐顺序第 6。第二年的硬工程作品；现在先占坑。  
> 来源：`web3_explore/doc/next/WEB3-DIRECTIONS.md`

## 概述

程序和钱包都要通过 RPC/gRPC 跟 Solana 说话。谁快谁慢，销售会吹。本仓库做中立秒表：同一事件到达各家的时间差，方法公开，持续出数字。

参照物：[yellowstone-thorofare](https://github.com/rpcpool/yellowstone-thorofare)（两两比、跑一次 JSON）。差距应是：多家横评、持续跑、公开面板、方法可复核。

## 你自己怎么用

以后选节点、做哨兵时看自己的表。不是每天打开的 App。

## 一开始

- 2～3 个**免费**端点
- 同一批 slot
- 核心指标：相对到达时间差（不要迷信本机绝对时钟）
- 先能打出 P50/P90/P99，再谈网站

Yellowstone gRPC 相关 crate 常是 **AGPL-3.0**。动手前确认依赖方式和传染范围，不要稀里糊涂链上 AGPL。

## 后面

历史图、方法论文档、供应商申诉渠道。有可复现的第一期结果再写 grant。

## 上限

被引用的公共榜 + grant + 供应商找你定制压测。成不了公链或交易所。收入偏慢、偏机构。

## 挣钱

Grant 和以后的赞助。不要当第一笔活命钱。RPC 账单自己先控制在免费档。

## 获客

每周更新数字本身就是内容。不一定要泡交易群。姿态必须中立，给对方复核渠道。
